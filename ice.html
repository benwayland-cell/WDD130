ICE Challenges

Prophet Card

This challenge had us applying our CSS knowledge to make a card that had information about the prophet.

Apostle Spotlight

This challenge entailed us using tags such as "display: flex;" to allow us to make elements on a page to line up into a grid. In this case we put several images of apostles into a grid.

Favorite Devo Table

This challenge had us using the "table" HTML tag. We put data from our favorite devotionals into a table.

Holiday Page

This challenge has us change the entire look of a website while exclusively using CSS.

Country Flags with Grid

This challenge had us practicing how "display: grid;" works. We made several flags by positioning and coloring divs using CSS.

CSS Positioning Activity

This challenge had us applying all we knew about using display grid to make rectangles appear in different ways on the screen.

Image Gallery Issues

This challenge didn't focus on editing HTML or CSS but instead had us optimizing the loading in of a web page. There were several images that were being displayed at a much smaller resolution as they were stored, so we made smaller resolution images and reduced the size of the image files by editing them in image software.

Signup Form Design

This challenge was to get us familiar with how to style form elements.
